# Инкремент 6: режимы захвата и настройки HKCU

Дата проверки: 2026-08-28

Реализовано:

- область — `Ctrl+Shift+1`;
- монитор под курсором — `Ctrl+Shift+3`;
- окно под курсором — `Ctrl+Shift+4` с DWM frame bounds и fallback на видимую
  область frozen desktop;
- все мониторы — через tray menu;
- открытие изображения через tray menu и командную строку;
- настройки schema v1 в `HKCU\Software\Screenshooter`;
- выбор папки сохранения по умолчанию через системный folder picker;
- открытие выбранной папки из tray menu;
- автозапуск через пользовательский `HKCU\...\Run`, по умолчанию выключен;
- повреждённая или неизвестная schema безопасно возвращает defaults.

Автоматически подтверждено:

- round-trip `HotkeysEnabled`, `AutostartEnabled` и `SaveFolder` в изолированном
  тестовом HKCU key;
- неизвестная schema не применяется;
- все 28 CTest-тестов Debug прошли.

Ограничение первой portable-сборки: режим окна использует точные DWM bounds, но
при отсутствии отдельного WGC frame показывает фактически видимое содержимое,
поэтому перекрывающее окно может попасть в результат.

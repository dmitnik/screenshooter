# Инкремент 1: базовый путь захвата

Дата проверки: 2026-08-28

Конфигурация: Windows 11 x64, один монитор 1920 × 1080, Debug.

Автоматизированный локальный smoke-сценарий:

1. Запущен `screenshooter.exe`; скрытый host и tray-процесс созданы.
2. Дважды инициирован путь `Ctrl+Shift+1` и выбрана область 460 × 270.
3. Подтверждено два независимых окна редактора.
4. В первом окне выполнена команда `Копировать`.
5. Подтверждено, что закрыто только первое окно, второе осталось открытым.
6. В clipboard подтверждены форматы `CF_DIBV5` и `PNG`.
7. Приложение штатно завершено.

Результаты измерения текущей машины:

- создание host: 34 мс;
- захват до появления первого overlay: 185 мс;
- повторный захват до появления overlay: 149 мс;
- редакторы после первого/второго захвата: 1/2;
- редакторы после Copy: 1;
- `CF_DIBV5`: доступен;
- `PNG`: доступен;
- процесс после команды выхода: завершён.

Отдельно проверить вручную перед выпуском:

- несколько физических мониторов, включая отрицательные координаты;
- смешанный DPI 100% + 150%;
- поворот экрана;
- `Esc` и правая кнопка мыши во время выбора;
- восстановление значка после перезапуска Explorer.

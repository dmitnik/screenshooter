# Screenshooter

A lightweight, portable Windows screenshot tool with annotation, cropping, blur,
and instant English/Russian language switching.

[Source code](https://github.com/dmitnik/screenshooter) · [MIT License](LICENSE)

Screenshooter — нативное локальное приложение для снимков экрана на Windows 10
1903+ и Windows 11. Оно работает одним процессом, обрабатывает снимки локально без облака
и распространяется как portable `screenshooter.exe`.

## Возможности текущей portable-версии

- единое меню по ЛКМ, ПКМ или клавиатурной активации значка в системном трее
  и настраиваемые глобальные сочетания (по умолчанию
  `Ctrl+Shift+1`, `Ctrl+Shift+3`, `Ctrl+Shift+4`);
- захват области, окна под курсором, монитора под курсором и всех мониторов;
- выбор области обновляется синхронно с движением мыши; светлая часть рамки
  показывает ровно те пиксели, которые откроются в редакторе;
- отдельное окно и независимая сессия для каждого снимка; новое окно сразу
  становится активным, получает клавиатурный фокус, центрируется на мониторе
  под курсором и не выходит за его рабочую область;
- вертикальная панель инструментов справа с официальными цветными SVG-глифами
  Tabler Icons `v3.46.0`, растрированными со сглаживанием в `20 × 20` при
  толщине линий `2`; ярким состоянием выбранного инструмента и более мягкой
  подсветкой при наведении; инструменты расположены в порядке: прямоугольник,
  эллипс, линия, стрелка, маркер, текст, размытие, обрезка, выбор;
- интерфейс редактора использует `Segoe UI 11 pt`, кнопки высотой `38 DIP`
  и масштабирование под DPI монитора; пустая нижняя полоса убрана;
- новое окно занимает около 65% ширины и высоты рабочей области монитора,
  центрируется и сразу вписывает снимок; на небольшом экране действует
  минимальный размер для доступности управления;
- при недостатке высоты инструменты прокручиваются отдельно от изображения;
- `Копировать в буфер и закрыть` и `Сохранить` закреплены внизу правой панели
  и остаются видимыми при прокрутке инструментов;
- кнопки `Настройки` и `Информация` находятся вверху правой панели;
  справка описывает основные сценарии, а единое окно настроек объединяет
  горячие клавиши, папку сохранения и автозапуск;
- текущий масштаб виден в панели; `100%` возвращает исходный размер,
  `Вписать` / `Ctrl+0` заполняет доступную область с сохранением пропорций,
  включая увеличение маленьких снимков; экспортируемое разрешение не меняется;
- `Tab` / `Shift+Tab` переключают элементы панели и прокручивают к ним,
  `Enter` / `Space` активируют кнопки;
- для прямоугольника, эллипса, линии, стрелки и текста доступна палитра из
  красного, зелёного, синего и чёрного цветов; цвет можно задать для следующего
  объекта или изменить у выделенного с поддержкой Undo/Redo;
- для текста доступны размеры `18`, `24`, `32`, `40`, `48 px`, полужирное,
  курсивное и подчёркнутое начертание; параметры применяются и к новым, и к
  выделенным текстовым объектам, а двойной щелчок по существующему тексту
  возобновляет редактирование его содержимого;
- выбор существующего объекта при любом активном инструменте, перемещение,
  изменение размера или направления за две управляющие точки, `Del` без
  подтверждения,
  keyboard nudge и Undo/Redo;
- прямоугольник, линия, эллипс, стрелка, полупрозрачный маркер и Unicode-текст;
  при создании
  `Shift` превращает прямоугольник в квадрат, эллипс в круг, а линию и стрелку
  фиксирует с шагом 45°; для маркера `Shift` создаёт строго горизонтальный
  прямой штрих; те же ограничения работают при изменении управляющих точек уже
  созданных элементов;
- линии, стрелки, прямоугольники, эллипсы и маркер рисуются со сглаженными
  краями без ступенчатой пикселизации;
- плотная квадратная пикселизация и Crop с предпросмотром; `Обрезать` выбран по
  умолчанию при открытии снимка, после завершения рамки `Применить` и `Отмена`
  появляются снаружи возле угла отпускания мыши, а `Esc` снимает рамку;
  применённая область становится новым исходником, а инструмент остаётся
  активным для следующей обрезки;
- Copy в `CF_DIBV5` + `PNG` с закрытием только текущего окна;
- Save As PNG/JPEG с именем `ГГГГ-ММ-ДД_ЧЧ-ММ-СС`, открытие файлов,
  drag-and-drop и вставка изображений; после сохранения приложение выделяет
  новый файл в Проводнике и переводит его окно на передний план, повторно
  используя уже открытую нужную папку;
- при изменении размера вставленного изображения `Shift` сохраняет пропорции
  исходника; клавишу можно нажать или отпустить прямо во время drag, в том числе
  после свободного искажения без дополнительного движения мыши;
- `Esc` удаляет выделенный объект; без выделения закрывает редактор и
  при наличии изменений предлагает сохранить их; ответ `Да` сохраняет PNG
  напрямую в выбранную папку по умолчанию без диалога, `Нет` закрывает без
  сохранения, `Отмена` оставляет редактор открытым; если папка не настроена,
  используется системная папка «Изображения»;
- настройки в `HKCU\Software\Screenshooter`, включая папку сохранения по
  умолчанию и автозапуск пользователя.

Курсор в снимок не включается. Собственные окна помечаются
`WDA_EXCLUDEFROMCAPTURE` на поддерживаемых версиях Windows.

## Быстрый старт

1. Запустите `screenshooter.exe` без прав администратора.
2. Нажмите `Ctrl+Shift+1` и выделите область либо выберите режим в меню трея.
3. Отредактируйте снимок.
4. Нажмите `Копировать в буфер и закрыть` или `Сохранить` внизу правой панели.

В меню трея можно открыть папку сохранения по умолчанию, а пункт `Настройки…`
открывает единое окно параметров. Те же настройки доступны по кнопке с
шестерёнкой в редакторе. Параметры хранятся в пользовательской ветке реестра.

## Язык интерфейса

По умолчанию используется English, в том числе при обновлении старых настроек без
сохранённого языка. В Settings → Language / Язык можно выбрать English или Русский.
Подписи настроек, открытых редакторов, подсказки и меню трея переключаются сразу,
без перезапуска. Save / Сохранить закрепляет выбор; Cancel / Отмена и закрытие окна
возвращают прежний язык. Снимки и пользовательский текст не переводятся.
Системные элементы диалогов открытия/сохранения и кнопки системных сообщений
следуют языку Windows; собственные подписи и сообщения приложения переведены.

## Сборка

Требуются Windows x64, Visual Studio Build Tools 2022 с C++ workload, Windows SDK,
CMake 3.28+ и Git. В настроенном x64 Developer environment:

```text
cmake --preset release
cmake --build --preset release
ctest --preset release
```

На текущей машине portable EXE собирается с `/MT`, поэтому отдельный Visual C++
Runtime пользователю не нужен. Catch2 загружается только для сборки тестов и в EXE
не входит.

Дополнительная проверка локализации требует интерактивного рабочего стола и
запускается отдельно (не входит в CTest). Из настроенного x64 Developer environment:

```text
cmake --build --preset debug --target localization_ui_smoke
out\build\debug\Debug\localization_ui_smoke.exe
```

Проверка открывает тестовый редактор и настройки, переключает оба языка,
проверяет Save/Cancel, сохранность введённых полей, порядок Tab и размеры подписей.
Пользовательские настройки в реестре не изменяются. Снимки тестовых окон сохраняются
в `out/localization-check/`; защита от захвата отключается только у тестовых окон.

Метрики capture и первого paint дополнительно выводятся локально через
`OutputDebugString`; телеметрия и сетевые запросы отсутствуют.

## Известные ограничения первой portable-версии

- Window capture использует DWM bounds и frozen visible-region fallback; если WGC
  недоступен, перекрывающее окно может попасть в снимок.
- Печать, подписанный installer и отдельная проверка Windows 10 остаются
  выпускными задачами после portable-версии.
- EXE пока не подписан сертификатом издателя.

Утверждённые требования находятся в `PLAN_WINDOWS_SCREENSHOT_APP.md`, инженерный
план — в `IMPLEMENTATION_PLAN_WINDOWS_SCREENSHOT_APP.md`, ручные протоколы — в
`tests/manual/`. Лицензии использованных компонентов приведены в
`THIRD_PARTY_NOTICES.md`.
